Sequential countdowns: each one starts by itself when the previous one ends, with its own colours.

Works and worklists

Tap a work to edit its countdowns. ▶ next to a work plays it alone: it stops at 00:00. ▶ Start on a worklist plays it as a set list: each work opens on its title, and when one ends the title of the next appears.

Starting from a point

On the title, the coloured bar works like the progress bar of an audio player: tap or drag the head, or use − and +, to start from any point. Reset brings you back to the same point.

Bluetooth pedal

Pair a page-turner pedal in the Bluetooth settings of Android, as a keyboard. On a title, right starts the work. On a countdown, right pauses and resumes, left resets to the title. On a title, left does nothing, so a stray press never changes the work.

Export and import

Export at the top saves all the worklists in one file; Export inside a worklist saves that one only. Import adds the worklists of a file to those already here, without replacing them. Use it to keep a copy, to move to another phone, or to load the worklists into the web version for ensembles. Export before uninstalling the app: its worklists are lost with it.
